## 1. 当前项目结论

项目已经具备主要页面、库存业务接口、文本/图片 Agent，以及手机端图片和语音输入代码。当前阶段以**整合、解决部署问题、真实设备及跨端业务验收**为主，同时仍有若干产品功能尚未实现。

- **Flutter 手机端**：游客和登录后的 Home、AI Assistant、Profile 及主要子页已实现；单件库存业务已接 API；近期已按效果图调整 UI，并保留同学的图片、相机和 Agent 功能。
- **Flutter Web / Render**：已有浏览器平台文件、构建脚本和测试站。此前已确认测试站展示过新版 UI；最新语音修复已提交，本机远程跟踪分支也指向该提交，但 Render 是否已部署完成仍需确认。
- **React Web**：已经有用户库存、空间、临期、文本助手和管理员账户页面，不再是早期文档中的占位工程。
- **FastAPI 后端**：认证、空间、目录、库存、数量操作、历史、批量处理、临期汇总、管理员账户及多模态 Agent 有实现和历史测试记录。
- **主要未闭环事项**：线上库存/临期接口曾返回 500 并伴随 CORS 报错；部署中的图片请求契约曾落后于代码；iPhone 真实语音、真实图片识别入库及跨端数据一致性尚未完成验收。
- **尚未实现的产品能力**：真实密码找回/修改、第三方登录、资料跨设备同步、实际通知调度、完整会话历史、真实语音额度等，需由团队确定交付优先级。

### 2.3 最新语音修复

当前流程为：

```text
文字模式点击麦克风
  → 仅切换成语音栏
  → 按住语音栏中间区域开始英文识别
  → 输入栏上方显示监听状态及已返回的识别文字
  → 松开停止采集，等待最终识别结果
  → 将结果追加到已有文字，进入可编辑输入框
  → 用户检查后手动发送到现有 Agent
```

- 识别语言根据本次用户测试设置为英文 `en-US`，当前没有新增语言选择器。
- 文字模式的麦克风图标无论点击还是长按，都不会直接启动识别。
- 中间语音栏按下开始、松开结束；向上滑动超过约 60 个逻辑像素再松开可取消。
- 已有输入文字保留，识别结果不会自动发送。
- 修复浏览器开始监听事件晚于 `listen()` 返回时被提前判失败的问题。
- 松开后等待最终转写回调，避免过早读取空文字；等待设置了时间上限。
- 处理首次授权期间松手、取消后的迟到结果，以及重新进入页面后监听回调绑定的问题。
- 权限、网络、未识别到文字等状态有可恢复提示。

技术边界：继续使用 `speech_to_text 7.5.0`，调用设备/浏览器提供的识别能力；App 没有把录音文件上传给 FastAPI，也没有新增音频存储接口。这不代表浏览器底层识别一定离线运行。部分文字是否即时返回取决于目标浏览器的识别支持。

验证边界：已有单元/页面测试，并在真实浏览器中使用受控语音回调检查完整交互；尚未证明 iPhone 麦克风收音、英文识别准确率和系统权限流程已通过真机验收。

相关实现：[语音服务](../mobile/lib/services/voice_input_service.dart)、[按住说话组件](../mobile/lib/widgets/hold_to_speak_button.dart)、[Agent 会话页](../mobile/lib/screens/agent_conversation_screen.dart)。

### 5.2 库存接口 500 与 CORS

此前用户截图显示，来自 Render 的库存及 `expiry-summary` 请求访问 Vercel 后端时，出现 500 和缺少 `Access-Control-Allow-Origin` 的浏览器报错。

- 这可以确认请求失败，但不足以确定服务端具体异常。
- 500 响应未带 CORS 头也可能使浏览器同时报告跨域错误，不能只调整前端错误文字就宣称已修复。
- 当前后端代码已有 CORS 中间件；需检查实际部署的版本、允许来源和异常响应路径，而不是继续把“尚未编写 CORS”当作现状。
- 更早的只读检查发现共享数据库缺少 `inventory_item.notes` 和 `agent_inventory_action`。这是排查线索，不是已确认的本次线上 500 根因，也不证明这些结构现在仍缺失。
- Tim 没有后端管理员权限，运行日志、数据库结构及 Vercel 配置应由后端/部署负责人核查并反馈。

### 5.3 图文 Agent 的远端契约

## 7. 建议的完整验收顺序

在团队确认的测试环境中执行，并记录前端提交、后端部署版本、日期、设备/浏览器、测试结果：

- [ ] 确认 Render 与 Vercel 使用目标版本，OpenAPI 契约和 CORS 配置一致。
- [ ] 新测试用户注册、登录、刷新恢复、退出；验证错误密码和 token 过期。
- [ ] 创建首个空间，选择有效分类/物品定义，完成手工入库。
- [ ] Home、库存列表、搜索、详情、临期汇总能读取同一条真实记录。
- [ ] 编辑日期/备注/位置；完成增加、消耗、比例消耗、盘点、丢弃/归档并核对历史。
- [ ] 文本 Agent 查询库存；验证精确操作、估算确认、多候选选择、取消和实际结果。
- [ ] 实拍图片/小票生成候选，补图/编辑后确认，检查服务端库存且无重复记录。
- [ ] iPhone 按住说英文、查看反馈、松手编辑、手动发送；上滑取消不插入、不发送。
- [ ] 中断网络、重复提交、关闭重开及旧提案冲突后，能核实原请求且不重复写入。
- [ ] 同一测试账号在 Flutter 与 React 重读数据一致；换账号后无数据残留。
- [ ] 在目标手机浏览器/主屏幕模式下复核导航位置、键盘、图片和语音权限。

业务完成的证据应是后端返回与重新读取的库存/历史结果，不能仅凭 AI 回复“已完成”或页面弹出成功提示。
