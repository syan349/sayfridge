# SayFridge Mobile

SayFridge 的 Flutter 手机端，面向 Android 和 iOS。当前目录只包含 Flutter 官方脚手架，业务页面将在后续迭代中实现。

## 环境要求

- Flutter SDK
- Android Studio / Android SDK（Android 开发）
- Xcode（iOS 开发，仅 macOS）

## 本地运行

```bash
flutter pub get
flutter run
```

## 基础检查

```bash
flutter analyze
flutter test
```

应用包名：`com.appix.sayfridge`。
